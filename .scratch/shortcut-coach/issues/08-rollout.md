## Question

How should the reversible opt-in development integration and the Key Promoter improvements be distributed and validated before upstream action reporting is available? Decide contribution order, supported/tested version policy, installation and removal ownership, transition to an upstream interface, and what happens if the upstream proposal is not accepted. Preserve the rule against automatic edits to packaged Omarchy files. This ticket plans rollout; it does not publish, install, or submit contributions.
